File: ../fonts/pixel.woff2
Actual family: SowVillage Pixel (site subset of Fusion Pixel 12px Proportional,
Simplified Chinese / zh-Hans)
Project: https://github.com/TakWolf/fusion-pixel-font
Downloaded from the project's official specimen website:
https://fusion-pixel-font.takwolf.com/fusion-pixel-12px-proportional-zh_hans.otf.woff2
Copyright (c) 2022, TakWolf (https://takwolf.com).
License: SIL Open Font License 1.1; full license retained in fusion-pixel-OFL.txt.
This is a subset containing the current page text and common symbols. Glyph
outlines, widths and hinting are retained; unused characters are removed.
The modified font family is renamed SowVillage Pixel. The complete original
is retained in the private source at artwork/source-assets/fonts/pixel.woff2.
The CSS alias "Zpix" is an internal integration name; this asset is not the
Zpix font by SolidZORO.
Use multiples of 12px where practical for crisp pixel edges.
